# Structure gallery

Open `structures.html` in a modern browser. The page is self-contained and works offline; no server or external resources are needed.

The gallery shows 3,109 relaxed 100-atom structures spanning 60 elements. Search by element, formula, or anonymous sample ID, switch between gallery and catalog views, and open individual structure previews.

`catalog.csv` contains the same anonymous sample IDs and formulas as the page. The gallery is a visual preview; the original calculation files are distributed separately.
