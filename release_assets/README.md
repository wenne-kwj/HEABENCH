# Release assets

`manifest.csv` records the prepared assets, their paths within the local
release directory, and sizes. The large archives are
excluded from Git; the HTML, PNG, documentation are tracked.

Upload the listed assets when publishing
the corresponding GitHub Release. The three numbered archives are independent
raw examples. `nsp_sp_example.tar.gz` includes all three spin-setting variants;
they do not need to be uploaded again separately. `structure_gallery.zip`
contains the self-contained HTML and anonymous catalog.

These are preview/sample assets, not the full task-specific training bundles.
The source tree and this inventory can be prepared before the assets are
published; the inventory alone does not certify public download availability.
